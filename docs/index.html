01 · SKILL

A method, written down

A directory with a SKILL.md: how to price, how to audit a funnel, how to write for LinkedIn. Forty-nine come from a pinned third-party catalog; two are ours. An agent reads one before working and names it in the deliverable.

What it adds: knowledge that can be cited.

02 · AGENT

A persona with a narrowed catalog

A system prompt plus the list of skills that persona may use. The catalog is hermetic: the absolute path of every allowed skill is injected into the prompt, so a skill outside the list does not exist as far as the model is concerned.

What it adds: judgement, bounded.

03 · WORKFLOW

Phases, artifacts, gates

An ordered set of phases. Each names its agent, what it produces, and what it requires. A phase is not done until its artifact is on disk — the runner checks and fails if it is missing. Some phases stop and wait for a person.

What it adds: a sequence that cannot be skipped.

house rules

Injected into every phase, of every workflow, for every client

No number without an origin

A number does not enter a deliverable unless it came from something run in that session. Not memory, not an industry average, not a reasonable estimate.

Assumptions carry their sensitivity

Saying "this is an estimate" is not enough. Name the assumption and say what breaks the conclusion if it is wrong.

A declared hole beats a plausible number

If the data cannot be obtained, the deliverable says so and why. An invented figure that looks right is the failure mode this system exists to prevent.

Nothing publishes itself

Workflows write drafts and plans. Pressing the button is always an explicit human action — no phase touches a client account.

The deliverable is the client's

The system runs in English; the work ships in the client's language, their vocabulary, their brand. Set per client, injected per phase.

A phase that failed is reported

Not simulated. The runner verifies the artifact reached disk and fails loudly if it did not, whatever the model claimed.

Skills vendored and pinned from a third-party catalog under MIT. Personas, workflows, gates and the runner are original. Switching vertical — marketing today, data or development tomorrow — means adding a row to method.yaml and re-running setup. Not one line of the runner changes.
